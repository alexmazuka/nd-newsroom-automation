# ✅ Чекліст куратора сайту (перед публікацією)

Кожен пункт — обов'язковий. AI-драфт — це заготовка, відповідальність за публікацію — на кураторові.

## Верифікація
- [ ] Першоджерело визначене і надійне; для подій на ТОТ — **мінімум два незалежні підтвердження**
- [ ] Усі позначки `[ПЕРЕВІРИТИ: …]` з драфта зняті (факт підтверджено або прибрано)
- [ ] Цифри, дати, імена, посади, назви населених пунктів звірені з джерелом
- [ ] Цитати дослівні, з вказанням, кому і де сказано

## Текст
- [ ] Заголовок відповідає фактам (без перебільшення) і зрозумілий без контексту
- [ ] Лід відповідає на «що сталося» у перших двох реченнях
- [ ] Термінологія за редакційною політикою
- [ ] Бекграунд не застарів (перевірити останні події за темою)

## Оформлення і SEO
- [ ] Фото/ілюстрація: права з'ясовані, підпис і alt-текст заповнені
- [ ] Yoast: focus keyphrase, SEO title (≤60), meta description (≤155) — індикатор не червоний
- [ ] Рубрика і теги проставлені; слаг латиницею
- [ ] Внутрішні посилання на 1–2 попередні матеріали за темою

## Після публікації
- [ ] Статус у дашборді → «На сайті» (запускає соцадаптацію М4)
- [ ] Якщо тема потребує відео — підтвердити таск для відділу відео
