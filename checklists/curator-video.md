# ✅ Чекліст куратора відео

Таск на сюжет приходить із дашборда (М5) разом з AI-заготовкою: сценарій, шотліст, титри, обкладинка.

## Перед монтажем
- [ ] Сценарій звірений з опублікованим текстом новини (фактаж ідентичний)
- [ ] Позначки `[ЗНАЙТИ ФУТАЖ]` закриті: архів редакції / офіційні джерела / графіка
- [ ] Права на всі футажі, фото і музику з'ясовані

## Монтаж (Final Cut)
- [ ] Використано шаблон проєкту (шапка, плашки, шрифти за брендбуком)
- [ ] Хук у перші 3 секунди
- [ ] Субтитри: Whisper-транскрипція **вичитана вручну** (імена, топоніми, цифри)
- [ ] Вертикальна версія 9:16 для Reels/Shorts + горизонтальна за потреби

## Публікація
- [ ] Обкладинка з Canva-шаблону, текст ≤ 6 слів
- [ ] Опис відео: 2 речення + посилання на матеріал на сайті + теги
- [ ] Статус у дашборді → «Відео опубліковано»
