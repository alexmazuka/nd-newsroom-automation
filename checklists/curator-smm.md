# ✅ Чекліст куратора SMM (перед автопостингом)

Соцверсії генеруються автоматично після публікації на сайті (М4). Перед натисканням ✅ у боті:

- [ ] Факти в постах збігаються з опублікованою новиною (AI не додав нічого від себе)
- [ ] Тон відповідає платформі: FB — розгорнуто + питання; TG — факт першим рядком; X — ≤270 знаків
- [ ] **Безпека:** на фото/відео немає облич і локацій, які можуть зашкодити людям на ТОТ; геолокації чутливих об'єктів не розкриті
- [ ] Посилання веде на правильний матеріал і відкривається
- [ ] Обкладинка/картка з Canva-шаблону за брендбуком (якщо передбачена)
- [ ] Час публікації: терміново → одразу; не терміново → у слот пікового охоплення
- [ ] Після постингу: статус у дашборді → «У соцмережах»
