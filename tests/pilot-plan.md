# 🧪 Протокол пілота: 10 матеріалів (місяць 5)

Мета — виміряти реальний ефект системи проти baseline і знайти вузькі місця до повного запуску.

## Дизайн пілота

- **10 матеріалів через нову систему** (мінімум: 6 новин, 2 розширені матеріали, 2 з відео-версією).
- **Контроль:** того ж тижня 5 матеріалів робляться старим процесом — для чесного порівняння.
- Кожен матеріал веде той куратор, який працюватиме з системою постійно (не «чемпіон» проєкту).

## Що фіксуємо по кожному матеріалу

| Поле | Як міряти |
|---|---|
| Тип матеріалу | новина / розширений / з відео |
| Час: подія → картка в боті | автоматично (n8n лог) |
| Час: «беремо» → чернетка готова | автоматично |
| Час: чернетка → публікація на сайті | вручну куратор |
| Час: публікація → пости в соцмережах | автоматично |
| Кількість правок куратора в AI-драфті | суб'єктивно: мало / помірно / переписав |
| Кількість позначок `[ПЕРЕВІРИТИ]` | з тексту драфта |
| Фактичні помилки, що дійшли до публікації | **має бути 0** |
| Дубль перехоплено антидублем? | так / ні / хибне спрацювання |
| Вийшло в 3 каналах (сайт+соц+відео)? | так / ні |

## Критерії приймання пілота

- ✅ Медіана повного циклу (подія → сайт + соцмережі) ≤ **30 хв** для новин
- ✅ **0** фактичних помилок у публікаціях
- ✅ 100% матеріалів пройшли через кураторське затвердження (перевірка логів)
- ✅ ≥ 8 із 10 матеріалів вийшли одночасно на сайті та в соцмережах
- ✅ Куратори оцінюють систему ≥ 4/5 (коротке опитування після пілота)

## Після пілота

1. Розбір: де застрягали матеріали (лог n8n + таблиця).
2. Корекція промптів у [prompts/](../prompts/) — типові правки кураторів стають правилами промпта.
3. Рішення go/no-go на повний запуск (місяць 6).
